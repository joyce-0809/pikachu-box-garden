# 皮卡丘的寶貝球大冒險

這是可直接部署到 GitHub Pages 的單頁推箱子遊戲。遊戲的 CSS、JavaScript 和繪圖程式都已內嵌在 `index.html`，不需要額外依賴或建置步驟。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的 **Public** repository。
2. 將此資料夾內的 `index.html` 和 `README.md` 上傳到 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`，目錄選 `/(root)`，再按 **Save**。
5. 等待 Pages 部署完成，GitHub 會在 Pages 設定頁顯示公開網址，格式通常是 `https://<帳號>.github.io/<repository>/`。

遊戲支援方向鍵、WASD、復原、重來、提示及手機觸控操作。
